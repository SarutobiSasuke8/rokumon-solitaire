# Project Brief: Solitaire

## Executive Summary
A browser and mobile-friendly Klondike Solitaire web app designed with rich aesthetics, zero-latency touch controls, procedural audio, customizable themes, and victory card cascade physics.

## Core Features
- Klondike Solitaire rules engine (Draw 1 & Draw 3 options)
- 7 Tableau piles, 4 Foundation piles, Stock, and Waste piles
- Drag and drop card interaction with touch support + tap-to-move alternative
- Undo / Redo move stack
- Hint engine (calculates valid moves and highlights them)
- Auto-complete solver sweep when remaining face-down cards are zero
- Bouncing card cascade canvas victory animation
- LocalStorage stats tracking (Win count, win rate, best time, fewest moves)
- 4 rich themes: Classic Felt, Midnight Luxury, Cyberpunk Neon, Royalty Gold
