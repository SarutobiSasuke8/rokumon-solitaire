# Input Control Map

| Action | Mouse Input | Touch Input | Keyboard Shortcut |
|---|---|---|---|
| Select / Drag Card | Left Click + Drag | Touch + Drag | — |
| Single Tap Auto-Move | Single Click | Single Tap | — |
| Double Click Auto-Move | Double Click | Double Tap | — |
| Draw Stock Card | Click Stock Pile | Tap Stock Pile | `Space` |
| Undo Move | Click Undo Button | Tap Undo Button | `Ctrl + Z` / `Cmd + Z` |
| Redo Move | Click Redo Button | Tap Redo Button | `Ctrl + Y` / `Cmd + Y` |
| Get Hint | Click Hint Button | Tap Hint Button | `H` |
| Auto Finish | Click Auto Finish | Tap Auto Finish | `A` |
| New Game | Click New Game | Tap New Game | `N` |
